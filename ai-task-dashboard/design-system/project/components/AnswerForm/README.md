# AnswerForm

AIからの質問に答えるフォーム。確認待ちの行を開いたときに、その行の真下に出す。

- 渡すもの：`id`、`agent`、`question`（`text`・`context`・`options[{id, label, hint}]`）、`draft`（`{option, note}`。閉じても入力を残すため親が持つ）、`error`、`busy`、`onChange(patch)`、`onSubmit()`、`onLater()`。
- 上から：質問の囲み（`wait-soft` の地・`wait-text` の枠。誰からの質問か・質問・背景）→ 選択肢（ラジオ）→ 補足（任意のテキスト）→ 主ボタン「回答を送信」と `quiet`「あとで」→ 送信後に何が起きるかの1文。
- 選択肢が無い質問では、テキスト欄が「回答」になり必須になる。
- 未入力で送信 → `error` に「選択肢を1つ選ぶか、補足欄に回答を書いてください。」を渡し、エラー文へフォーカスを移す。
- 送信失敗 → 入力を残したまま `error` に理由と次の行動を渡す。
- 送信成功 → 親がタスクを「作業中」に変え、同じ場所に `Notice`（success）と「取り消す」を出す。
