# Dashboard

12件の架空タスクで組んだダッシュボード全体の動く見本。絞り込み・詳細・回答・回答後の状態変更・取り消し・0件・エラーをすべて試せる。

- 試し方：「次にやること」の「回答する」→ 何も選ばず「回答を送信」（入力エラー）→ 選んで送信（行が「作業中」に変わり、閉じると「作業中」の群へ移る）。
- AI停止の行は「対処する」から再試行・別のAIへの引き継ぎができる。
- 上部の「プロトタイプ用の切り替え」で、データ0件・読み込みエラー・送信失敗を出せる。
- 部品はすべて `window.AIDash` のもの。画面固有のレイアウトだけをこのページの `<style>` に書いている。
