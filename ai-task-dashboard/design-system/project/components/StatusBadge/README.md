# StatusBadge

タスクの状態を「印（色の円＋記号）」と「言葉」で示すバッジ。状態を表示する場所では必ずこれを使い、色だけ・記号だけで状態を示さない。

- 渡すもの：`status`（`'wait' | 'stop' | 'run' | 'done'`）。言葉は自動で「確認待ち／AI停止／作業中／完了」になる。`label` で上書きできるが、4語以外に言い換えない。
- 印だけが要る場所（群の見出し・パネルの見出し）は `StatusMark({ status, large })` を使う。印は `aria-hidden` なので、近くに必ず言葉を置く。
- 一覧の行では左端に置き、その下に経過時間（「42分待ち」）を `t-meta` で添える。
- しない：バッジを押せるようにする（絞り込みは `SummaryTile` と `FilterChip` で行う）。
