# SummaryTile

状態ごとの件数を大きく見せるタイル。押すとその状態で一覧を絞り込み、もう一度押すと解除する。

- 渡すもの：`status`、`count`、`pressed`（絞り込み中か）、`onClick`。`note` で下の補足文を上書きできる（既定は「あなたの返答で再開」など）。
- 4枚を「止まっている（確認待ち・AI停止）」「動いている（作業中）」「終わった（完了）」の3つの見出しの下にまとめて置く。見出しにも件数を書く。
- 件数は全体の件数（担当AIや検索の絞り込みに左右されない）。
- 選択中は `ink` の2px枠・`*-soft` の地・「✓ 絞り込み中」の文字で示す。`aria-pressed` が付く。
- 0件でも押せる（押すと空状態が出る）。
